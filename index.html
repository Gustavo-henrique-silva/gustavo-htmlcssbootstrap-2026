Primeira Página usando HTML com Bootstrap

Bootstap é um framework de desenvolvimento web criado originalmente pelo Twitter que facilita a criação de sites e aplicações responsivas.

Ele fornece componentes e estilos prontos usando principalmente HTML, CSS e JavaScript, permitindo desenvolver interfaces de forma mais rápida e consistente

Download

O Bootstrap pode ser baixado gratuitamente pelo site oficial. Ele oferece arquivos CSS e JavaScript prontos para facilitar a criação de sites responsivos. Também é possível utilizar o Bootstrap diretamente no projeto por meio de um CDN, sem precisar baixar os arquivos.
